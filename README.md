Delayed Alert
Type a notification, choose a delay, and your iPhone sends it to you later. Pending alerts can be cancelled.
Build (free, no Mac): upload this whole folder (including .github) to a new GitHub repository,
then Actions > Build IPA > Run workflow, download the DelayedAlert-ipa artifact, and install the .ipa with
Sideloadly or AltStore using a free Apple ID (re-sign every 7 days).
